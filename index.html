① 题意复述与坐标约定
题目条件（预设，可一键恢复）

标量衍射；λ = 500 nm；衍射屏到观察屏 L = 50 cm；孔面入射振幅均匀 A = 1（实数）。第一问：圆孔内入射场同相（等相位面与孔面重合），半径 r 从 0 增大，数值积分求轴上 O′ 点光强 I(r)；用误差判据界定 I ∝ r⁴ 的范围；覆盖 ≥ 5 个完整振荡周期，自动找出并精化极大、极小；从数值曲线求第 4 个极大半径，作为第二问默认半径。

坐标

光沿 +z 从衍射屏（孔面，z = 0）传到观察屏（z = L）。孔面坐标 (X, Y)，原点在轴上；观察屏坐标 (X′, Y′)，原点 O′ 为轴与观察屏交点。题图把竖直轴标为 X(Y)、X′(Y′)，本项目取 +X、+X′ 向上；X、Y、z 构成右手系，迎着光看（光朝向观察者）时 +Y 向左。第一问只用 O′ = (0, 0)。

时谐因子与相位符号

场写作 Re[U e−iωt]，向 +z 传播的平面波为 e+ikz，点源球面波为 e+ikR/R。因此“相位延迟 φ”表示复振幅乘 e+iφ（第二问情形 3 将沿用此约定）。

② 标量衍射积分、传播核、面积权重、单位与归一化
U(P) = (1/(iλ)) ∬Σ Uinc(Q) · (z/R) · eikR/R · dS，　I(P) = |U(P)|² 第一类瑞利–索末菲积分（略去 (1 − 1/(ikR)) 因子，相对影响 ≤ 1/(kL) ≈ 1.6×10⁻⁷）。倾斜因子 z/R 与 1/R 球面波衰减都保留；先把所有面元的复振幅相加，再取模平方。孔面同相仍有传播光程 R 造成的相位差 kR。
O′ 点：U(O′) = (A/(iλ)) ∫₀r 2πρ · (L/R) · eikR/R · dρ，　R = √(L² + ρ²) 圆对称：环带面积权重 dS = 2πρ dρ。实际求积：把 [0, r] 分成宽度 ≤ h 的面板，每个面板用 n 点 Gauss–Legendre，节点权重 = wi·(h/2)·2πρi。相位用 k(R − L) = kρ²/(R + L) 计算，避免 kR ≈ 6.3×10⁶ rad 的大数相减；输出约化场 U′ = U·e−ikL，|U′|² = |U|²。
归一化：A = 1，Iinc = |A|² = 1；图中纵轴 I/Iinc = |U|²/|A|² 用同一积分约定计算“不加遮挡的平面波”在 O′ 的光强 I₀：validate.js 用高斯渐变孔径（w = 10 mm）数值积分得 I₀ = 0.99999937（w = 10 mm；w = 2、5 mm 时分别为 0.99960437、0.99998987，与高斯光束近似验算一致，w → ∞ 时 → 1；见 validation/validation_report.md）。因此 I/Iinc 与 I/I₀ 相同；极大值接近 4 = (2|A|)²。单位：所有长度内部以米计算，nm / μm / mm / cm 仅在显示与输入处由 Diffraction.UNITS 统一换算；光强以 Iinc 为单位（无量纲）。
解析式只作独立验算（虚线，默认关闭） 近轴/菲涅耳近似下 I/I₀ = 4 sin²[k(√(L²+r²) − L)/2]，小孔首项 (πr²/(λL))²；极值光程条件 √(L²+r²) − L = nλ/2。这些式子从不用于生成曲线、极值、r⁴ 区间或第 4 极大半径，只用于在表格中给出“与数值结果的差”。

⑤ 物理分析：为什么小孔 I ∝ r⁴？为什么出现极大极小？
小孔：I ∝ r⁴

当 r 很小，孔内所有点到 O′ 的光程差 ΔR ≈ r²/(2L) ≪ λ/2（即 NF ≪ 1），各子波几乎同相，复振幅直接按面积相加：|U| ≈ (1/λ)·πr²/L ∝ r²，于是 I = |U|² ∝ r⁴。本页的 C 由数值积分在 rs = 10⁻³√(λL) 处求得，偏差 ε(r) = |I/(Cr⁴) − 1| 随 r 增大而增大；默认 5% 阈值给出适用区约 NF ≲ 0.25。超出后边缘子波相位明显落后，相量开始弯曲，I 增长变慢。

极值：菲涅耳半波带

以 O′ 为中心、按 R = L + nλ/2 把孔面划分为半波带。相邻半波带对 O′ 的贡献相位相反、大小几乎相等（倾斜因子和 1/R 缓慢减小）。孔内含奇数个半波带时剩余一个未抵消的带 → 极大（≈ 4I₀）；含偶数个时几乎完全抵消 → 极小（≈ 0）。半波带边界 rn² ≈ nλL，所以振荡在 r² 或 NF 上近似等间隔（周期 ΔNF = 2），在 r 上并不等间隔：Δr ≈ λL/r 逐渐变小。相量图中这就是振动曲线绕圆一周（2 个半波带）回到原点。极大值随 n 缓慢下降（倾斜因子 L/R）。

② 采样方案、权重、误差与抽检（本图实际采用）

源平面采样与观察面采样分开。源间距由观察区角点光程差 ≤ λ/q 决定；8π 倾斜只约束线性相位情形。FFT 窗口至少盖住 2(W+a)，顶到点数上限时会放宽源间距并在状态栏用红标写出实际达到的 λ/q。二维图样用同一 RS1 核的零填充 FFT 卷积生成。同相 / 线性用极坐标直接积分抽检；随机固定格按单元格积分；逐点独立用与 FFT 相同的源像素求和。不是远场/夫琅禾费近似。

情形 2 · 随机相位（单次实现，不是时间平均）

逐点独立（题目预设）：每个源采样点的相位彼此独立、均匀于 [0, 2π)，δ 就等于源间距 d。换预览 / 标准 / 高精会换一套采样点，图样跟着变，没有连续极限。可比的量是平均光强 ≈ Ncell·(δ²/λL)²，约为同相相干叠加的 1/N。这是一次实现，不是时间平均。

固定单元格（演示）：相位画在边长固定的正方形上（默认 40 μm）。像素若跨过格边界，按重叠面积对 eiφ 加权，不再把整格相位赋给中心落在哪一侧。加密网格只是更密地采样同一块状场，不重抽随机数。种子经 Hash(seed, ix, iy) 决定，点「重新生成」才换实现。

情形 3 · 沿 X 线性相位 8π：图样朝 +X′ 平移，并不等同于同相
相位约定

孔顶（X = +r）相对孔底（X = −r）延迟 8π：φ(X) = 8π(X + r)/(2r)，φ 为相位延迟，复振幅乘 e+iφ（时谐因子 e−iωt）。沿 Y 为常数。两端相位模 2π 相同，但孔径上累积了 4 个波长的连续光程梯度，并不因为两端同余就回到同相情形。

偏移方向

φ 随 +X 增大，等效为波矢 kx = 4π/r > 0 的倾斜平面波，主瓣应朝 +X′（向上） 平移。几何估计 ΔX′ = L tan(arcsin(2λ/r))。剖面图上的虚线是这一预计位置；数值峰值应落在其附近。偏移方向与“延迟端”一致：波前在孔顶落后，光束偏向延迟的一侧。

情形 4 · 泊松亮斑与巴比涅原理（复振幅相减）
圆屏的实现

不把积分域换成“孔外的整个无限平面”（那在数值上不稳定），而是用同一传播核、同一归一化：U′disk = U′free − U′hole。不加遮挡的平面波在约化约定下 U′free = A = 1，I0 → 1。光强是 |Udisk|²，不是 Ifree − Ihole。

轴上泊松亮斑

同相圆孔在第 4 极大处 U′hole ≈ 2（I ≈ 4），于是 U′disk ≈ 1 − 2 = −1，Idisk(O′) ≈ 1。不透明圆屏的几何阴影中心出现接近 I0 的亮斑，这就是泊松亮斑。它与圆孔轴上光强通过巴比涅关系互相决定：Idisk(O′) = |1 − U′hole(O′)|²。
