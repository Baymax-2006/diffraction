1. 模型与方法

题目预设：波长 λ = 500 nm，衍射屏到观察屏 L = 50 cm，入射振幅 A = 1（实数，孔内均匀）。轴上半径从 0 扫到 2.2 mm。第一问固定为标准档，读 Diffraction.PRECISION.standard：面板光程差 ≤ λ/20，Gauss–Legendre 8 点，半径采样 4000 点，只调用 computeQ1。第二问的四张图在圆孔上取子光源，把复振幅直接相加。

U(P) = (1/(iλ)) ∬ A · t · (L/R) · eikR/R  dx dy，   I = |U|² 第一类瑞利–索末菲。t 在透光部分为 1、在不透明部分为 0；R 是面元到观察点的距离，倾斜因子 L/R 和球面波 1/R 都保留。先把各面元的复振幅加起来，再取模平方，不能先对光强做面积平均。略去严格核中的 (1 − 1/(ikR))，相对大小约 1/(kL) = …。

第二问把这同一个积分写成圆孔上的子光源求和，R 仍然是精确距离，没有旁轴近似：

U(X′,Y′) = (d²/(iλ)) Σj tj · L · eikRj / Rj² Rj = √[(X′−xj)² + (Y′−yj)² + L²]，I = |U|²。子光源是孔内的网格点 (xj, yj)，每个代表面积 d²；tj 是该点的复透过率。观察屏上的一个点，就是把所有子光源的这项加起来，再取模平方。

归一化用 I/Iinc = |U|²/|A|²。A = 1，所以 Iinc = 1。计算时提出公共相位 eikL，累加约化场 U′ = U e−ikL（|U′|² = |U|²），相位写成 k(R − L) = kρ²/(R + L)，避免 kR 的大数相减。时谐因子取 e−iωt，相位延迟 φ 表示复振幅乘 e+iφ。圆屏用的就是这个 U′。

光沿 +z，从孔面 z = 0 到观察屏 z = L。孔面坐标 (X, Y)，观察屏 (X′, Y′)，原点在轴上。+X 与 +X′ 向上；(X, Y, z) 是右手系，迎着光看时 +Y、+Y′ 向左。图上的二维图按这个方向画：竖直轴是 X′，水平轴是 Y′，左边是 +Y′。

子光源是什么：把圆孔分成边长为 d 的小方块，每块用中心一个点光源代替，复振幅乘上这块的面积 d² 和透过率 tj。点只取在孔内，x² + y² ≤ a²，a 是第一问求出的 r₄。同相圆孔 tj = 1；沿 X 的线性相位 tj = exp(i·8π(x+a)/(2a))；随机相位每个点一个独立的 φ = 2π Hash(种子, m, n)，m、n 是网格下标。

d 怎么取：看观察区角点。孔内离这个角点最远的横向距离是 ρmax = a + √2·W/2，W = 5 mm 是观察区边长。沿这条最远方向，相邻两个子光源的光程差上界是 (ρmax/R)·d，R = √(ρmax²+L²)。令上界等于 λ/10，并且把 d 取得尽量大（尽量稀疏）：d = (λ/10)·R/ρmax，不再放宽。采样表里的 λ/x 是网格上轴向相邻两点到角点的实际最大 |ΔR|，它比上界小一些，因为最坏方向往往不落在网格轴上。8π 的入射相位写在 tj 里，四种图用同一个 d。

观察屏上的每个点单独做上面的求和。屏的网格不必和源一样密。视场是以 O′ 为中心的 5 mm × 5 mm。随机相位散斑的特征尺寸大约 λL/(2a) ≈ 94 μm，屏间距要明显小于它，这里取 25 μm，一边 201 个点。源点数 N 和每一张图的加法次数 N×201² 在采样表里。每次打开页面都重新计算，不使用缓存，也不用事先存好的图。
